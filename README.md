## 🚐 VanLife Rental App (React)

A modern van rental platform inspired by Airbnb, built with React. This application allows users to browse van listings, authenticate securely, and simulate booking with integrated payment (Stripe test mode).

## 🚀 Live Demo

👉 [https://travel-van.netlify.app/](https://travel-van.netlify.app/)

## 📌 Overview

VanLife is a frontend-focused rental application where users can explore available vans, view detailed listings, and book rentals. It includes authentication, test payment integration, and data visualization features.

Frontend

⚙️ Installation & Setup
# Clone the repository
git clone [https://github.com/adammuana20/vanlife.git](https://github.com/adammuana20/vanlife.git)

# Navigate into the project
cd your-repo-name

# Install dependencies
npm install

# Setup environment variables
Create a .env file and add the following:

VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=

VITE_STRIPE_PUBLISHABLE_KEY=

# Run development server
npm run dev
📦 Deployment

Deployed on Netlify.
